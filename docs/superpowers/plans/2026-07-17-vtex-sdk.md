# VTEX TypeScript SDK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a production-grade, multi-account TypeScript SDK for the VTEX API — full endpoint coverage generated from VTEX's official OpenAPI schemas, with hand-written ergonomic facades over the hot APIs.

**Architecture:** Three stacked layers. A hand-written **core** (`fetch`, auth, retry, rate-limit, typed errors) is called by a **generated** layer (`raw.*`, 1,061 endpoints from 75 OpenAPI schemas), which is called by hand-written **facades** (orders, catalog, checkout, pricing, masterData, logistics) that add auto-pagination and clean names. Each `VtexClient` is immutable and bound to one account; a factory resolves/caches clients per account.

**Tech Stack:** TypeScript, Node ≥18 (native `fetch`), Vitest (tests), tsup (dual ESM/CJS build). No runtime HTTP dependency.

## Global Constraints

- **Runtime:** Node ≥18 only. Use the global `fetch`/`AbortController`/`AbortSignal` — no `axios`, `node-fetch`, or other HTTP dependency.
- **No global state:** every `VtexClient` is immutable and bound to one account. No module-level mutable singletons.
- **Credentials are server-side:** `appKey`/`appToken` must never be logged or serialized by the SDK.
- **Auth headers (exact):** `X-VTEX-API-AppKey`, `X-VTEX-API-AppToken`, `VtexIdclientAutCookie`.
- **Base URL:** `https://{account}.{environment}.com.br`, default `environment = 'vtexcommercestable'`.
- **Rate limiting:** on `429`, honor the `Retry-After` response header (seconds) when present; otherwise exponential backoff with jitter. Default `maxRetries = 3`.
- **Default timeout:** `30000` ms per request.
- **Generated code is committed** to `src/generated/` — never generated at install/build time.
- **Content-type matching:** treat any response/request content-type whose value starts with `application/json` as JSON.
- **Module format:** ESM source, dual ESM+CJS output, `"type": "module"`, `"sideEffects": false`.

```ts
import type { VtexEnvironment } from './types.js'

export function resolveBaseUrl(account: string, environment: VtexEnvironment = 'vtexcommercestable'): string {
  if (!account) throw new Error('VTEX account is required')
  return `https://${account}.${environment}.com.br`
}

export function buildQuery(query?: Record<string, unknown>): string {
  if (!query) return ''
  const params = new URLSearchParams()
  for (const [key, value] of Object.entries(query)) {
    if (value === undefined || value === null) continue
    if (Array.isArray(value)) {
      for (const v of value) params.append(key, String(v))
    } else {
      params.append(key, String(value))
    }
  }
  const s = params.toString()
  return s ? `?${s}` : ''
}
```

```ts
import type { VtexClientConfig } from './types.js'

export function buildAuthHeaders(config: VtexClientConfig): Record<string, string> {
  if (config.appKey || config.appToken) {
    if (!config.appKey || !config.appToken) {
      throw new Error('Both appKey and appToken are required for app-key authentication')
    }
    return {
      'X-VTEX-API-AppKey': config.appKey,
      'X-VTEX-API-AppToken': config.appToken,
    }
  }
  if (config.authCookie) {
    return { VtexIdclientAutCookie: config.authCookie }
  }
  throw new Error('No VTEX credentials provided: supply appKey/appToken or authCookie')
}
```

```ts
export class VtexRequestError extends Error {
  readonly status: number
  readonly body: unknown
  readonly requestId?: string
  readonly retryAfter?: number

  constructor(message: string, opts: { status: number; body: unknown; requestId?: string; retryAfter?: number }) {
    super(message)
    this.name = new.target.name
    this.status = opts.status
    this.body = opts.body
    this.requestId = opts.requestId
    this.retryAfter = opts.retryAfter
  }
}

export class VtexAuthError extends VtexRequestError {}
export class VtexNotFoundError extends VtexRequestError {}
export class VtexValidationError extends VtexRequestError {}
export class VtexRateLimitError extends VtexRequestError {}
export class VtexServerError extends VtexRequestError {}

function parseRetryAfter(headers: Headers): number | undefined {
  const raw = headers.get('Retry-After')
  if (!raw) return undefined
  const n = Number(raw)
  return Number.isFinite(n) ? n : undefined
}

export function mapResponseToError(status: number, body: unknown, headers: Headers): VtexRequestError {
  const requestId = headers.get('x-request-id') ?? headers.get('x-vtex-request-id') ?? undefined
  const retryAfter = parseRetryAfter(headers)
  const base = { status, body, requestId, retryAfter }
  const msg = `VTEX request failed with status ${status}`
  if (status === 401 || status === 403) return new VtexAuthError(msg, base)
  if (status === 404) return new VtexNotFoundError(msg, base)
  if (status === 400 || status === 422) return new VtexValidationError(msg, base)
  if (status === 429) return new VtexRateLimitError(msg, base)
  if (status >= 500) return new VtexServerError(msg, base)
  return new VtexRequestError(msg, base)
}
```

```ts
export function shouldRetry(status: number | undefined, attempt: number, maxRetries: number): boolean {
  if (attempt >= maxRetries) return false
  if (status === undefined) return true // network error
  if (status === 429) return true
  return status >= 500
}

export function computeBackoff(attempt: number, retryAfter: number | undefined, rand: () => number): number {
  if (retryAfter !== undefined) return retryAfter * 1000
  const base = Math.pow(2, attempt) * 200
  const jitter = Math.floor(rand() * 100)
  return base + jitter
}
```

```ts
import type { VtexClientConfig, RequestOptions } from './types.js'
import { resolveBaseUrl, buildQuery } from './url.js'
import { buildAuthHeaders } from './auth.js'
import { mapResponseToError } from './errors.js'
import { shouldRetry, computeBackoff } from './retry.js'

const sleep = (ms: number) => new Promise((r) => setTimeout(r, ms))

async function parseBody(res: Response): Promise<unknown> {
  if (res.status === 204 || res.status === 205) return undefined
  const ct = res.headers.get('content-type') ?? ''
  const text = await res.text()
  if (!text) return undefined
  if (ct.startsWith('application/json')) {
    try { return JSON.parse(text) } catch { return text }
  }
  return text
}

export class VtexHttpClient {
  private readonly baseUrl: string
  private readonly authHeaders: Record<string, string>
  private readonly maxRetries: number
  private readonly timeoutMs: number
  private readonly doFetch: typeof fetch
  private readonly hooks: NonNullable<VtexClientConfig['hooks']>

  constructor(config: VtexClientConfig) {
    this.baseUrl = resolveBaseUrl(config.account, config.environment)
    this.authHeaders = buildAuthHeaders(config)
    this.maxRetries = config.maxRetries ?? 3
    this.timeoutMs = config.timeoutMs ?? 30000
    this.doFetch = config.fetch ?? fetch
    this.hooks = config.hooks ?? {}
  }

  async request<T>(opts: RequestOptions): Promise<T> {
    const url = this.baseUrl + opts.path + buildQuery(opts.query)
    const hasBody = opts.body !== undefined
    const headers: Record<string, string> = {
      Accept: 'application/json',
      ...this.authHeaders,
      ...opts.headers,
    }
    if (hasBody) headers['Content-Type'] = 'application/json'

    let attempt = 0
    // eslint-disable-next-line no-constant-condition
    while (true) {
      const controller = new AbortController()
      const timeout = setTimeout(() => controller.abort(), opts.timeoutMs ?? this.timeoutMs)
      const signal = opts.signal
        ? AbortSignal.any([opts.signal, controller.signal])
        : controller.signal

      this.hooks.onRequest?.({ method: opts.method, url, attempt })

      let res: Response
      try {
        res = await this.doFetch(url, {
          method: opts.method,
          headers,
          body: hasBody ? JSON.stringify(opts.body) : undefined,
          signal,
        })
      } catch (err) {
        clearTimeout(timeout)
        if (shouldRetry(undefined, attempt, this.maxRetries)) {
          const delay = computeBackoff(attempt, undefined, Math.random)
          this.hooks.onRetry?.({ method: opts.method, url, attempt, delayMs: delay, reason: 'network' })
          await sleep(delay)
          attempt++
          continue
        }
        throw err
      }
      clearTimeout(timeout)

      this.hooks.onResponse?.({ method: opts.method, url, status: res.status, attempt })

      if (res.ok) return (await parseBody(res)) as T

      const body = await parseBody(res)
      if (shouldRetry(res.status, attempt, this.maxRetries)) {
        const retryAfterHeader = res.headers.get('Retry-After')
        const retryAfter = retryAfterHeader ? Number(retryAfterHeader) : undefined
        const delay = computeBackoff(attempt, Number.isFinite(retryAfter) ? retryAfter : undefined, Math.random)
        this.hooks.onRetry?.({ method: opts.method, url, attempt, delayMs: delay, reason: `status ${res.status}` })
        await sleep(delay)
        attempt++
        continue
      }
      throw mapResponseToError(res.status, body, res.headers)
    }
  }
}
```

```ts
function camelCase(input: string): string {
  const parts = input
    .replace(/[^a-zA-Z0-9]+/g, ' ')
    .trim()
    .split(/\s+/)
    .filter(Boolean)
  if (parts.length === 0) return 'op'
  return parts
    .map((p, i) => (i === 0 ? p.charAt(0).toLowerCase() + p.slice(1) : p.charAt(0).toUpperCase() + p.slice(1)))
    .join('')
}

export function methodName(op: { operationId?: string }, httpMethod: string, path: string): string {
  if (op.operationId && op.operationId.trim()) return camelCase(op.operationId)
  // Derive: method + path segments, turning {param} into "ByParam".
  const segments = path.split('/').filter(Boolean).map((seg) => {
    const m = seg.match(/^\{(.+)\}$/)
    return m ? `by ${m[1]}` : seg
  })
  return camelCase([httpMethod, ...segments].join(' '))
}

export function dedupe(names: string[]): string[] {
  const seen = new Map<string, number>()
  return names.map((name) => {
    const count = seen.get(name) ?? 0
    seen.set(name, count + 1)
    return count === 0 ? name : `${name}${count + 1}`
  })
}

export function tagToNamespace(tag: string): string {
  return camelCase(tag.replace(/&/g, ' '))
}
```

```ts
export function schemaToType(schema: any, refName: (ref: string) => string): string {
  if (!schema || typeof schema !== 'object') return 'unknown'
  if (schema.$ref) return refName(schema.$ref)
  if (schema.enum) return schema.enum.map((v: unknown) => JSON.stringify(v)).join(' | ')
  if (schema.allOf) return schema.allOf.map((s: any) => schemaToType(s, refName)).join(' & ')
  if (schema.oneOf) return schema.oneOf.map((s: any) => schemaToType(s, refName)).join(' | ')
  if (schema.anyOf) return schema.anyOf.map((s: any) => schemaToType(s, refName)).join(' | ')

  switch (schema.type) {
    case 'string': return 'string'
    case 'number':
    case 'integer': return 'number'
    case 'boolean': return 'boolean'
    case 'array': return `${schemaToType(schema.items ?? {}, refName)}[]`
    case 'object':
    default: {
      const props = schema.properties
      if (!props) return schema.type === 'object' ? 'Record<string, unknown>' : 'unknown'
      const required: string[] = schema.required ?? []
      const lines = Object.entries(props).map(([key, sub]) => {
        const opt = required.includes(key) ? '' : '?'
        const safeKey = /^[A-Za-z_$][A-Za-z0-9_$]*$/.test(key) ? key : JSON.stringify(key)
        return `  ${safeKey}${opt}: ${schemaToType(sub, refName)}`
      })
      return `{\n${lines.join('\n')}\n}`
    }
  }
}
```

```ts
import { methodName } from './naming.js'
import { schemaToType } from './types.js'

interface Ctx {
  httpMethod: string
  path: string
  op: any
  refName: (ref: string) => string
}

function jsonContent(container: any): any | undefined {
  const content = container?.content
  if (!content) return undefined
  const key = Object.keys(content).find((k) => k.startsWith('application/json'))
  return key ? content[key].schema : undefined
}

function successSchema(op: any): any | undefined {
  const responses = op.responses ?? {}
  const code = Object.keys(responses).find((c) => c.startsWith('2')) // 200/201/202/204
  if (!code) return undefined
  return jsonContent(responses[code])
}

export function generateMethod(ctx: Ctx): string {
  const { httpMethod, path, op, refName } = ctx
  const name = methodName(op, httpMethod, path)
  const params: any[] = op.parameters ?? []
  const pathParams = params.filter((p) => p.in === 'path')
  const queryParams = params.filter((p) => p.in === 'query')
  const bodySchema = jsonContent(op.requestBody)
  const retSchema = successSchema(op)
  const retType = retSchema ? schemaToType(retSchema, refName) : 'unknown'

  // Options-object type
  const optionFields: string[] = []
  for (const p of [...pathParams, ...queryParams]) {
    const opt = p.required ? '' : '?'
    optionFields.push(`  ${p.name}${opt}: ${schemaToType(p.schema ?? {}, refName)}`)
  }
  if (bodySchema) optionFields.push(`  body: ${schemaToType(bodySchema, refName)}`)
  const optionsType = optionFields.length ? `{\n${optionFields.join('\n')}\n}` : 'Record<string, never>'

  // Interpolated path
  const tsPath = path.replace(/\{([^}]+)\}/g, (_m, g) => `\${params.${g}}`)

  const queryObj = queryParams.length
    ? `{ ${queryParams.map((p) => `${JSON.stringify(p.name)}: params.${p.name}`).join(', ')} }`
    : undefined

  const callFields = [
    `method: '${httpMethod.toUpperCase()}'`,
    `path: \`${tsPath}\``,
  ]
  if (queryObj) callFields.push(`query: ${queryObj}`)
  if (bodySchema) callFields.push(`body: params.body`)

  return [
    `  ${name}(params: ${optionsType}): Promise<${retType}> {`,
    `    return this.http.request<${retType}>({ ${callFields.join(', ')} })`,
    `  }`,
  ].join('\n')
}
```

- [ ] **Step 1: Implement `scripts/codegen.ts`**

```ts
import { readdir, readFile, mkdir, writeFile, rm } from 'node:fs/promises'
import { join } from 'node:path'
import { methodName, dedupe, tagToNamespace } from './codegen/naming.js'
import { schemaToType } from './codegen/types.js'
import { generateMethod } from './codegen/operation.js'

const HTTP_METHODS = ['get', 'post', 'put', 'patch', 'delete'] as const
const refName = (r: string) => r.split('/').pop()!

function slugify(title: string): string {
  return title.toLowerCase().replace(/[^a-z0-9]+/g, '-').replace(/^-|-$/g, '')
}

async function main() {
  const dir = 'schemas'
  const files = (await readdir(dir)).filter((f) => f.endsWith('.json'))
  await rm('src/generated', { recursive: true, force: true })
  await mkdir('src/generated', { recursive: true })

  const rawImports: string[] = []
  const rawFields: string[] = []

  for (const file of files) {
    const doc = JSON.parse(await readFile(join(dir, file), 'utf8'))
    const title: string = doc.info?.title ?? file.replace(/\.json$/, '')
    const slug = slugify(title)
    const apiClass = title.replace(/[^a-zA-Z0-9]/g, '') + 'Api'

    // Types file
    const schemas = doc.components?.schemas ?? {}
    const typeLines = Object.entries(schemas).map(
      ([name, schema]) => `export type ${name} = ${schemaToType(schema, refName)}\n`,
    )
    await mkdir(join('src/generated', slug), { recursive: true })
    await writeFile(join('src/generated', slug, 'types.ts'), typeLines.join('\n') || 'export {}\n')

    // Group operations by namespace(tag)
    const groups = new Map<string, string[]>() // namespace -> method code[]
    const nameTracker = new Map<string, string[]>() // namespace -> method names (for dedupe)

    for (const [path, item] of Object.entries<any>(doc.paths ?? {})) {
      for (const m of HTTP_METHODS) {
        const op = item[m]
        if (!op) continue
        const tag = (op.tags && op.tags[0]) || title
        const ns = tagToNamespace(tag)
        const code = generateMethod({ httpMethod: m, path, op, refName })
        if (!groups.has(ns)) { groups.set(ns, []); nameTracker.set(ns, []) }
        groups.get(ns)!.push(code)
        nameTracker.get(ns)!.push(methodName(op, m, path))
      }
    }

    // Re-run dedupe per namespace by rewriting method names deterministically
    // (generateMethod already used methodName; dedupe collisions by suffixing in code text).
    const nsClasses: string[] = []
    const nsFields: string[] = []
    for (const [ns, methods] of groups) {
      const names = dedupe(nameTracker.get(ns)!)
      const dedupedMethods = methods.map((code, i) => {
        const original = nameTracker.get(ns)![i]
        const deduped = names[i]
        return deduped === original ? code : code.replace(`  ${original}(`, `  ${deduped}(`)
      })
      const className = `${apiClass}_${ns}`
      nsClasses.push(
        `class ${className} {\n` +
        `  constructor(private http: VtexHttpClient) {}\n` +
        dedupedMethods.join('\n\n') +
        `\n}`,
      )
      nsFields.push(`  readonly ${ns}: ${className}`)
    }

    const indexSource = [
      `import type { VtexHttpClient } from '../../core/http.js'`,
      `import type * as T from './types.js'`,
      ``,
      ...nsClasses,
      ``,
      `export class ${apiClass} {`,
      ...nsFields,
      `  constructor(http: VtexHttpClient) {`,
      ...[...groups.keys()].map((ns) => `    this.${ns} = new ${apiClass}_${ns}(http)`),
      `  }`,
      `}`,
      ``,
    ].join('\n')

    rawImports.push(`import { ${apiClass} } from './${slug}/index.js'`)
    rawFields.push({ ns: tagToNamespace(title), cls: apiClass, slug } as any)
  }

  // RawNamespaces aggregator
  const nsNames = new Map<string, { cls: string }>()
  for (const f of rawFields as any[]) nsNames.set(f.ns, { cls: f.cls })
  const aggregator = [
    `import type { VtexHttpClient } from '../core/http.js'`,
    ...rawImports,
    ``,
    `export class RawNamespaces {`,
    ...[...nsNames].map(([ns, { cls }]) => `  readonly ${ns}: ${cls}`),
    `  constructor(http: VtexHttpClient) {`,
    ...[...nsNames].map(([ns, { cls }]) => `    this.${ns} = new ${cls}(http)`),
    `  }`,
    `}`,
    ``,
  ].join('\n')
  await writeFile('src/generated/index.ts', aggregator)

  console.log(`Generated ${files.length} API namespaces into src/generated/`)
}

main().catch((err) => { console.error(err); process.exit(1) })
```

```ts
import type { VtexEnvironment, VtexHooks } from './core/types.js'
import { VtexClient } from './client.js'

export type VtexCreds = { appKey: string; appToken: string } | { authCookie: string }

export interface VtexFactoryConfig {
  credentials: (account: string) => VtexCreds | Promise<VtexCreds>
  environment?: VtexEnvironment
  maxRetries?: number
  timeoutMs?: number
  fetch?: typeof fetch
  hooks?: VtexHooks
}

export function createVtexFactory(config: VtexFactoryConfig) {
  const cache = new Map<string, Promise<VtexClient>>()

  async function build(account: string): Promise<VtexClient> {
    const creds = await config.credentials(account)
    return new VtexClient({
      account,
      environment: config.environment,
      maxRetries: config.maxRetries,
      timeoutMs: config.timeoutMs,
      fetch: config.fetch,
      hooks: config.hooks,
      ...creds,
    })
  }

  return {
    forAccount(account: string): Promise<VtexClient> {
      let entry = cache.get(account)
      if (!entry) {
        entry = build(account)
        cache.set(account, entry)
      }
      return entry
    },
    clear(account?: string): void {
      if (account) cache.delete(account)
      else cache.clear()
    },
  }
}
```

```ts
export async function* paginate<T>(
  fetchPage: (page: number) => Promise<{ items: T[]; hasMore: boolean }>,
  startPage = 1,
): AsyncGenerator<T> {
  let page = startPage
  // eslint-disable-next-line no-constant-condition
  while (true) {
    const { items, hasMore } = await fetchPage(page)
    for (const item of items) yield item
    if (!hasMore || items.length === 0) return
    page++
  }
}
```

```ts
import { paginate } from './pagination.js'

export interface OrderListFilters {
  status?: string
  q?: string
  orderBy?: string
  perPage?: number
  [key: string]: unknown

interface OrdersPage {

  paging: { currentPage: number; pages: number; total: number; perPage: number }

export class OrdersFacade {
  constructor(private readonly http: VtexHttpClient) {}

  get(orderId: string): Promise<unknown> {

  }

  list(filters: OrderListFilters = {}): AsyncGenerator<unknown> {
    const { status, perPage, ...rest } = filters
    const http = this.http
    return paginate<unknown>(async (page) => {
      const query: Record<string, unknown> = {
        page,
        per_page: perPage ?? 100,
        ...rest,
      }
      if (status !== undefined) query['f_status'] = status
      const res = (await http.request({ method: 'GET', path: '/api/oms/pvt/orders', query })) as OrdersPage
      const paging = res.paging ?? { currentPage: page, pages: page }
      return { items: res.list ?? [], hasMore: paging.currentPage < paging.pages }
    })
  }
}
```

```ts
export interface ScrollOptions { fields?: string[]; size?: number; query?: string; sort?: string }

export class MasterDataFacade {

  get(dataEntity: string, id: string): Promise<unknown> {
```

````markdown
TypeScript SDK for the VTEX API. Full endpoint coverage generated from VTEX's

## Quick start
```ts
import { VtexClient } from 'vtex-sdk'

const vtex = new VtexClient({ account: 'lojax', appKey: process.env.VTEX_APP_KEY!, appToken: process.env.VTEX_APP_TOKEN! })

// Facade with auto-pagination
for await (const order of vtex.orders.list({ status: 'ready-for-handling' })) {
  console.log(order)
}

```ts
import { createVtexFactory } from 'vtex-sdk'

const factory = createVtexFactory({
  credentials: async (account) => loadCredsFor(account), // env, vault, or DB
})
const lojaY = await factory.forAccount('lojay')
```

## Errors
All failures throw a typed error: `VtexAuthError`, `VtexNotFoundError`,
`VtexValidationError`, `VtexRateLimitError` (with `.retryAfter`), `VtexServerError`.

## Auth & environments
App-key auth (`appKey`/`appToken`) or user token (`authCookie`). Default
environment is `vtexcommercestable`; pass `environment: 'vtexcommercebeta'` to target beta.

## Rate limiting
On HTTP 429 the SDK honors `Retry-After` and retries with exponential backoff +
jitter, up to `maxRetries` (default 3).
````
